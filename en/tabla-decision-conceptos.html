Decision Tree — What Concept to Use on a New Page?

Does the page sell or present a physical product (variator, board, equipment) to quote?
YES → Is this a product page with pricing/a datasheet? → E-shop · If it is direct sale LP → Equipment
NO ↓
Does the page describe a highly specialized technical service (turbogenerators, maintenance, oil & gas, suppression systems)?
YES → Specialized Services · Indigo · Hives
NO ↓
Is the page geared towards a specific industrial sector (mining, agro-industry, food)?
YES → Sectoral + corresponding sector: mineria / Agribusiness / food-drinks
NO ↓
Does the page present company capabilities, equipment, processes or is it a point of contact?
YES → Corporate · RX/cobalt · applies to ≥8 pages
NO → Consult with the team before creating a new concept

Rules of use by concept

Corporate — navy & cobalt

  • Use in institutional pages without sectoral guidance
  • Never use sector colors (green, amber, night) on these pages
  • Hero gradient: dark to navy to cobalt
  • Type: Roboto Condensed 400/700 — No exceptions
  • Main CTA: #0F4C81

Sectoral — variable color by sector

  • The concept color changes depending on the sector with data-sector
  • The HTML structure is identical between the 3 sectors
  • Always include: KPI strip, 6 service cards, timeline, standards, ref-grid, 7 FAQs
  • JSON-LD required: Service + FAQPage
  • Nav marker ✓ active in the corresponding sector

Equipment — technical slate

  • Always include technical specifications table
  • Use .norm-badge for IEC/IEEE/NOM standards
  • Copper accent #D97706 only for outstanding values of the SM
  • JSON-LD: Product + FAQPage
  • More sober Hero: no radial glow, preferred technical image

Specialised Services — Indigo

  • Include urgency/24/7 availability badge
  • Benefits checklist before the contact form
  • Floating CTA on mobile (sticky bottom position)
  • JSON-LD: Service + FAQPage
  • Roboto Condensed — never Segoe UI on these pages

E-shop — slate + orange

  • Orange #F97316 only for CTA purchase/quota and prices
  • Maintain VMS identity in logo and nav (navy)
  • JSON-LD: Product (with offers and price)
  • Include downloadable technical sheet (PDF link)
  • Do not mix with tokens of other concepts

Snippet implementation

Copy to <head> of each page, adjusting the attributes of <html>:

<!-- 1. Attributes in the html tag --> <html lang="es-MX" data-concept="Sectoral" data-sector="mineria"> <!-- 2. Link tokens.css FIRST in the <head> --> <link rel="stylesheet" href="tokens.css" /> <!-- 3. Then Google Fonts and the local <style> --> <link href="https://fonts.googleapis.com/css2?family=Roboto+Condensed:wght@400;700&display=swap" rel="stylesheet" /> <style> /* Use var(--concept-primary), var(--concept-hero-gradient), etc. */ .hero { background: var(--concept-hero-gradient); } .kpi-strip { background: var(--concept-kpi-bg); } .kpi__val { color: var(--concept-kpi-val); } .btn--primary { background: var(--concept-btn-primary); } </style>
